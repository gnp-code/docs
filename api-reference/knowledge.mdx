The Knowledge API is the core resource of Magpie Directive. It gives you full programmatic control over the entries that make up your knowledge base — from bulk ingestion pipelines to single-entry lookups. All endpoints are available at `/v1/knowledge` and follow standard REST conventions.

---

## List Entries

Retrieve a paginated list of knowledge entries in your workspace. Optionally filter by collection or tags.

```http
GET /v1/knowledge
```

### Query Parameters

<ParamField query="collection" type="string">
  Filter results to entries belonging to the specified collection slug (e.g., `product-docs`). Omit to return entries from all collections.
</ParamField>

<ParamField query="tags" type="string">
  A comma-separated list of tag names to filter by (e.g., `onboarding,guide`). Returns only entries that match **all** specified tags.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  The maximum number of entries to return per page. Minimum `1`, maximum `100`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  The number of entries to skip before returning results. Use with `limit` for pagination.
</ParamField>

### Example Request

```bash
curl "https://api.magpiedirective.com/v1/knowledge?collection=product-docs&tags=onboarding&limit=5" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

<ResponseField name="data" type="array">
  An array of knowledge entry objects matching your query.

  <Expandable title="Entry object fields">
    <ResponseField name="id" type="string">
      Unique identifier for the entry (e.g., `ent_abc123`).
    </ResponseField>
    <ResponseField name="title" type="string">
      The display title of the entry.
    </ResponseField>
    <ResponseField name="content" type="string">
      The full Markdown content of the entry.
    </ResponseField>
    <ResponseField name="tags" type="array of strings">
      Tags assigned to this entry.
    </ResponseField>
    <ResponseField name="collection" type="string">
      The slug of the collection this entry belongs to.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the entry was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the most recent update.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  The total number of entries matching your filter criteria (before pagination).
</ResponseField>

<ResponseField name="limit" type="integer">
  The page size used for this response.
</ResponseField>

<ResponseField name="offset" type="integer">
  The offset used for this response.
</ResponseField>

```json
{
  "data": [
    {
      "id": "ent_abc123",
      "title": "Getting Started with Magpie Directive",
      "content": "# Getting Started\n\nWelcome to Magpie Directive...",
      "tags": ["onboarding", "guide"],
      "collection": "product-docs",
      "created_at": "2024-01-15T10:30:00Z",
      "updated_at": "2024-01-20T08:15:00Z"
    }
  ],
  "total": 42,
  "limit": 5,
  "offset": 0
}
```

## Get Entry

Fetch a single knowledge entry by its ID.

```http
GET /v1/knowledge/{id}
```

### Example Request

```bash
curl https://api.magpiedirective.com/v1/knowledge/ent_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

```json
{
  "data": {
    "id": "ent_abc123",
    "title": "Getting Started with Magpie Directive",
    "content": "# Getting Started\n\nWelcome to Magpie Directive. This guide walks you through...",
    "tags": ["onboarding", "guide"],
    "collection": "product-docs",
    "custom_fields": {
      "author": "Jane Smith",
      "reviewed": true
    },
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-01-20T08:15:00Z"
  }
}
```

If no entry exists with the given ID, the API returns `404 Not Found`.

## Create Entry

Add a new knowledge entry to your workspace. Requires a **read-write** API key.

```http
POST /v1/knowledge
```

### Body Parameters

<ParamField body="title" type="string" required>
  The display title of the entry. Keep it concise and descriptive — it is used in search results and navigation.
</ParamField>

<ParamField body="content" type="string" required>
  The full body of the entry in Markdown format. You can include headings, lists, code blocks, and standard Markdown elements.
</ParamField>

<ParamField body="tags" type="array of strings">
  An optional list of tags to assign to the entry (e.g., `["api", "reference"]`). Tags are created automatically if they don't already exist.
</ParamField>

<ParamField body="collection" type="string">
  The slug of an existing collection to add this entry to (e.g., `product-docs`). If omitted, the entry is placed in your default collection.
</ParamField>

<ParamField body="custom_fields" type="object">
  An optional key-value object for storing structured metadata alongside the entry (e.g., `{"author": "Jane Smith", "version": "2.0"}`). Values can be strings, numbers, or booleans.
</ParamField>

### Example Request

```bash
curl -X POST https://api.magpiedirective.com/v1/knowledge \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "How to Configure Webhooks",
    "content": "# Webhooks\n\nWebhooks let you receive real-time notifications...",
    "tags": ["webhooks", "configuration"],
    "collection": "product-docs",
    "custom_fields": {
      "author": "Jane Smith",
      "reviewed": true
    }
  }'
```

### Response — 201 Created

```json
{
  "data": {
    "id": "ent_xyz789",
    "title": "How to Configure Webhooks",
    "content": "# Webhooks\n\nWebhooks let you receive real-time notifications...",
    "tags": ["webhooks", "configuration"],
    "collection": "product-docs",
    "custom_fields": {
      "author": "Jane Smith",
      "reviewed": true
    },
    "created_at": "2024-02-10T14:22:00Z",
    "updated_at": "2024-02-10T14:22:00Z"
  }
}
```

## Update Entry

Replace the fields of an existing knowledge entry. Requires a **read-write** API key. Send only the fields you want to change — omitted fields retain their current values.

```http
PUT /v1/knowledge/{id}
```

### Body Parameters

<ParamField body="title" type="string">
  Updated title for the entry.
</ParamField>

<ParamField body="content" type="string">
  Updated Markdown content for the entry. Replaces the entire content body.
</ParamField>

<ParamField body="tags" type="array of strings">
  Updated tag list. This **replaces** the existing tags entirely — include all tags you want the entry to have after the update.
</ParamField>

<ParamField body="collection" type="string">
  Move the entry to a different collection by providing the new collection slug.
</ParamField>

<ParamField body="custom_fields" type="object">
  Updated custom fields object. This **merges** with existing custom fields — provide only the keys you want to add or change.
</ParamField>

### Example Request

```bash
curl -X PUT https://api.magpiedirective.com/v1/knowledge/ent_xyz789 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "How to Configure and Test Webhooks",
    "tags": ["webhooks", "configuration", "testing"]
  }'
```

### Response — 200 OK

The response body follows the same structure as [Get Entry](#get-entry), returning the full updated entry object.

## Delete Entry

Permanently remove a knowledge entry from your workspace. Requires a **read-write** API key.

```http
DELETE /v1/knowledge/{id}
```

<Warning>
  Deletion is permanent and cannot be undone. The entry, its content, and all associated metadata are immediately removed from your knowledge base and will no longer appear in search results.
</Warning>

### Example Request

```bash
curl -X DELETE https://api.magpiedirective.com/v1/knowledge/ent_xyz789 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response — 204 No Content

A successful deletion returns HTTP `204 No Content` with an empty response body.
